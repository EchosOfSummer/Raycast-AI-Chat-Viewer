# Raycast AI Chat Viewer

Raycast AI Chat Viewer is a planned HTML interface for viewing exported Raycast AI chat conversations in a readable, browser-based format.

The project is currently being recovered from a Time Machine backup after a MacBook system reset. The original application save files are being located and will be uploaded to this repository when available.

## Planned Purpose

- Display exported Raycast AI conversations in a readable interface.
- Organize messages into clear conversation views.
- Make archived AI chats easier to browse outside of Raycast.
- Test the interface against real exported Raycast data.
- Troubleshoot formatting and display issues caused by exported conversation data.
